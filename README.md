## 🏴‍☠️ The Log

Sails Base mainnet like open water — charting mechanisms most wallets never touch, logging every voyage with a transaction hash instead of a sea shanty. No treasure map, just `docs/JOURNAL.md`.

- ⚓ **TrailKeeper** — an ERC-8004-registered agent that's this crew's ship's log: on-chain milestone badges, a paid `/report` via x402, a reputation trail a third party actually rated
- 🧹 **DustSweep** — plunders your own wallet clean: scans and revokes dead ERC-20 + Permit2 approvals before someone else plunders it for you
- 🗺️ Comfortable well past the shallows: native L1↔L2 crossings, a Solana bridge round trip, EIP-7702 delegation, gas paid entirely in USDC, Uniswap v3 swaps down to the last cent of dust
- 📜 Every voyage logged with tx hashes — if the log doesn't have it, it didn't happen
